# 🌐 Huokaing Thara Bank — Promotional Portal

Welcome to the official repository for the **Huokaing Thara Bank Promotional Portal**! This high-tech, cyber-secured web application delivers automated announcements, bilingual (Khmer and English) promotional details, an interactive Web Speech AI voice reader, and real-time event telemetry logs.

## ✨ Key Technical Features

1. **Bilingual Promotion Grid:** Structured cards displaying exclusive offers (such as the Citymall Supermarket 50% discount) in both Khmer (`km-KH`) and English (`en-US`).
2. **AI Voice Presentation Reader:** Powered by the browser's native Web Speech API (`speechSynthesis`), allowing users to listen to automated sequential voice announcements with animated waveform visualizers.
3. **Matrix Canvas Background:** Dynamic HTML5 Canvas background animation rendering continuous digital text streams.
4. **Responsive Glassmorphism UI:** Centered layout optimized for seamless cross-platform display across both desktop monitors and Android touchscreens.
5. **Live Telemetry Stream:** Real-time simulated security and operational logs updating dynamically.

## 📂 Project Structure

├── index.html       # Main HTML structure, promotional cards, and audio controls
├── style.css        # Cyberpunk neon theme, glassmorphism, and responsive layout
└── app.js           # Matrix canvas stream, Web Speech voice reader, and telemetry logs
